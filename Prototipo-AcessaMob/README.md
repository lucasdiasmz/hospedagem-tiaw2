# Protótipo AcessaMob — Agenda de Informações

Esta pasta contém somente o protótipo da funcionalidade de agenda de medicamentos e consultas, separado do repositório geral do grupo.

## Conteúdo

- `Codigo/`: aplicação independente feita com Next.js, React, JavaScript/JSX e CSS.
- `Referencias/wireframe.png`: cópia do wireframe utilizado para orientar a interface.
- `GUIA_IMPLEMENTACAO_AcessaMob.docx`: guia técnico com a estrutura dos arquivos e as instruções de execução.

## Executar

Abra um terminal dentro da pasta `Codigo` e rode:

```bash
npm install
npm run dev
```

Depois acesse `http://localhost:3000`.
